 metamorfoZ accompagne les territoires qui souhaitent bifurquer vers un modèle régénératif pour mieux protéger les personnes. Dans cette perspective, l'Adapatation au dérèglement climatique peut être un formidable moteur de transformation.

Nous nous appuyons autant que possible sur les dynamiques collectives existantes ou à créer, et sur une vision prospective renouvelée en permanence. Engagés depuis toujours sur les questions climat-biodiversité-circularité, nous sommes particulièrement préparés à accompagner les projets de territoire qui intègrent tout ou partie de ce qui pourrait être un modèle régénératif : sobriété, low-tech, matériaux locaux, implication des personnes, etc.

Notre valeur ajoutée dans des équipes qui abordent ces questions d'un point de vue principalement technique consiste justement à activer le facteur humain, celui qui peut faciliter, voire accélérer un projet vertueux, mais également, le freiner, voire le stopper.
